# Phase 4: Embeddings

This phase is a structure-only starting point. No embedding implementation or dependencies have been added.

The lessons planned for this phase are NumPy vectors, dot product, cosine similarity, Euclidean distance, real text embedding models, semantic similarity search, and Top-K retrieval.

Phase 3?s existing chunk JSON files are available at `../phase_3_chunking/outputs/` and can be read directly; this phase does not modify them.
