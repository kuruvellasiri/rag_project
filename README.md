# Traditional RAG Learning

A staged Python learning project covering foundations, document processing, chunking, and (when ready) embeddings. Each completed phase keeps its own source, data, dependencies, outputs, and tests where applicable.

- `shared_data/` holds the original Phase 3 Student Handbook PDF and OCR extraction output.
- `phase_0_python_foundation/` contains the Python exercises.
- `phase_1_rag_basics/` is reserved for the RAG basics phase.
- `phase_2_document_processing/` contains the completed multi-format loader.
- `phase_3_chunking/` contains the five separate chunking implementations and preserved outputs.
- `phase_4_embeddings/` is an empty implementation scaffold; its README describes the planned topics. It can read Phase 3 chunks from `phase_3_chunking/outputs/`.

See each phase README for its setup and run instructions.
